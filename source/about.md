# About C++ Questions

C++ Questions is a project by **Nhut Nguyen** to help junior developers practice
reading and reasoning about C++ used in everyday software.

Questions and full explanations are free to read without an account.

## How examples are checked

Each question identifies its language version and assumptions. Example programs
are kept in the repository and checked for their expected output. Explanations
also reference language rules: compiler output alone does not establish what
the C++ standard guarantees.

## Report a mistake

[Open an issue](https://github.com/ntnhut/cppquestions/issues) with the question
URL, the suspected error, and a reference or compiler example if available.
