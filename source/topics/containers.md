# Containers and iterators

Start with reading a vector's values using a range-based loop. Then try map
lookup, where reading with a subscript can add an entry. Vector erasure combines
iteration and modification and is intermediate practice.

**Starting knowledge:** Variables, loops, and addition. The map question also
introduces key-value pairs. Learn ordinary vector traversal and iterators before
the erasure question.

## Your learning path

1. Store values in a vector and read them with a range-based loop.
2. Distinguish a container's size from an element's index.
3. Store key-value pairs in a map and distinguish lookup from insertion.
4. Learn iterator positions and the past-the-end marker.
5. Practice erasing elements safely after those basics are comfortable.

Review [ownership and RAII](ownership.md) when reasoning about element lifetimes.
