# Containers and iterators

Practice how container operations affect stored elements and the iterators used
to reach them. Choose lookup and modification operations deliberately.

**Starting knowledge:** Standard containers, loops, references, and basic iterators.

## Your learning path

1. Distinguish an element, an iterator, and the past-the-end position.
2. Check which iterators and references an operation invalidates.
3. Use the iterator returned by erasure to continue a traversal safely.
4. Distinguish map lookup from insertion through a subscript.
5. Compare container choices using ordering, complexity, and stability needs.

Review [ownership and RAII](ownership.md) when reasoning about element lifetimes.
