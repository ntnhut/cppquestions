# Learning paths

A question can reveal a gap in understanding. Begin with variables,
initialization, conditions, loops, functions, strings, and simple classes.
Then practice passing values and references and using standard containers.
Start with the language-basics question, then functions and vector traversal.
Use the starting knowledge on each page to choose an appropriate question.

| Available topic | Starting knowledge | Current practice |
| --- | --- | --- |
| [Language basics](topics/fundamentals.md) | Integer variables and arithmetic | Basic counter initialization |
| [Functions and references](topics/functions.md) | Variables, assignment, and function calls | Basic value and reference parameters |
| [Containers and iterators](topics/containers.md) | Variables and loops; iterators for erasure | Basic vector traversal and map lookup, then intermediate vector erasure |
| [Ownership and RAII](topics/ownership.md) | Scope, constructors, and destructors; smart pointers for the code example | Basic cleanup terminology, then intermediate resource lifetime tracing |
| [Inheritance and polymorphism](topics/polymorphism.md) | Value/reference parameters, inheritance, and virtual functions | Optional intermediate practice on slicing and destruction |
| [Move semantics](topics/move-semantics.md) | Copy/move constructors, reference binding, const, and overload selection | Optional advanced practice on const and copying |

Move semantics and inheritance can wait until your code or study requires them.
Work through ordinary object use and container operations before these more
specialized examples.
