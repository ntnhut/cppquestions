# Learning paths

A question can reveal a gap in understanding. Use the topic paths to decide what
to study next and which prerequisites to review.

| Topic | Start with | Work toward |
| --- | --- | --- |
| [Ownership and RAII](topics/ownership.md) | Scope, object lifetime, constructors and destructors | Clear ownership and exception-safe resource handling |
| [Move semantics](topics/move-semantics.md) | References, const, and overload resolution | Reasoning about copy/move operations in practical code |
| [Classes and polymorphism](topics/polymorphism.md) | Classes, inheritance, references, and destructors | Safe base interfaces and avoiding object slicing |
| [Containers and iterators](topics/containers.md) | Containers, loops, and basic iterators | Safe traversal and choosing lookup or modification deliberately |
